# Security Policy

## Supported versions

Security fixes go into the latest version of the `plainhub` package on npm
(the CLI and the MCP server in `cli/`). Please update to the latest version first.

## Reporting a vulnerability

Please do not open a public issue for security problems.
Report it privately on GitHub: **Security → Report a vulnerability** in this repository.
Only the maintainers can see your report.

Please include what you found, how to reproduce it, and the version you used.
We will reply within 5 business days and keep you updated until it is fixed.

## Scope

- The CLI and the MCP server in this repository (`cli/`).
- The PlainHub app at app.plainhub.dev is a hosted service and is not in this repository,
  but you can report problems with it the same way.
